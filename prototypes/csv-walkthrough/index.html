    About this prototype

    This is a working draft for the docs team. It covers the same content as the current CSV walkthrough, reorganized around how someone working alone actually moves through it.

    Five parts instead of nineteen equal headings
    Each part opens by saying what you'll have when it's done. The old step 6 ("add objects, if necessary") was mostly a skip, so it's now a note.
    Each step names its app
    The walkthrough moves between GitHub.com, GitHub Desktop, VS Code, the terminal, and the browser. The coloured label under each title shows where to look.
    Screen clips start paused
    The GIFs are the same files, but each one shows its first frame until you press play. Actions with a clip get a "Show me" link that plays it, so the picture matches the sentence you're reading.
    Video is a choice, not a footnote
    The mode switch at the top decides whether each step opens on its video or its clips, and it's remembered. On the docs site the video plays in place. In this preview it links to YouTube, because the preview can't embed other sites.
    "You're done when…" checkpoints
    Every step ends with something you can see that confirms it worked. Marking a step done fills in the progress rail.
    Your names, filled in
    Commands and settings use the username and repository name you enter, so nobody has to translate username.github.io by hand.
    Save points
    Committing is taught once in step 9. After that it appears as a short "Save point" with a suggested message and the steps tucked inside, instead of a link back up the page.
